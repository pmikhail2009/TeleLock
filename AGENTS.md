# Обязательные правила проекта

Эти инструкции действуют во всех чатах и для всех агентов, работающих с проектом Telelock.

## Название проекта

- Использовать название Telelock во всех новых текстах, интерфейсах и документации.
- Прежние технические идентификаторы допустимы для совместимости существующих установок, привязок и адресов сервисов.

## Git после обновления бота

- После каждого обновления бота сразу создавать Git-коммит с внесёнными изменениями, выполнив необходимые проверки.
- Не считать обновление завершённым до создания коммита. В итоговом ответе указывать хеш коммита.
- Включать в коммит только изменения текущей задачи; не добавлять секреты, `.env` и посторонние изменения пользователя.
- Если коммит невозможен (например, отсутствует Git-репозиторий), явно сообщить причину пользователю; не утверждать, что коммит создан.
- Отправка коммита в удалённый репозиторий (`git push`) выполняется по отдельному указанию пользователя.
