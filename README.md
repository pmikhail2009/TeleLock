# Telelock v-0.2

[Скачать pak01_dir.vpk](https://github.com/pmikhail2009/TeleLock/releases/latest/download/pak01_dir.vpk)

## Что нового в v-0.2

- Добавлен выбор языка Telelock: русский или английский.
- Язык можно сменить в настройках мода в Deadlock или через кнопку «Язык» в Telegram-боте. Выбор синхронизируется между игрой и ботом.

## Установка

Скачайте `pak01_dir.vpk` и поместите его в папку `game/citadel/addons`.
