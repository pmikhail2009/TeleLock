# Telelock

Telelock — авторский мод для Deadlock с управлением поиском матча и уведомлениями через Telegram.

[Скачать Telelock (ZIP)](downloads/Telelock.zip?raw=true)

## Что такое VPK Telelock

VPK — формат архивов, из которых Deadlock загружает игровые ресурсы. Файл `pak01_dir.vpk` содержит игровую часть Telelock. Когда архив установлен в папку `game/citadel/addons` и игра запущена, в меню **Esc** появляется панель Telelock.

Я сделал Telelock, чтобы можно было запустить поиск матча с телефона и получить уведомление в Telegram, когда Deadlock найдёт матч.

### Что внутри архива

В архиве четыре изменённые разметки интерфейса и три скрипта. Интерфейс Deadlock называется Panorama.

| Разметки | Что делает Telelock |
| --- | --- |
| Меню Esc и главное меню | Показывает настройки и подключение к Telegram. Получает команды, пока игра запущена. |
| Окно выбора героев | Подтверждает выбранный состав штатной кнопкой Deadlock. Игра сама проверяет, можно ли начать поиск. |
| Индикатор поиска | Определяет, начался ли поиск, ждёт ли игра участников группы или уже подключается к матчу. |

Telegram-бот, сервер и веб-панель работают отдельно от архива. Игра открывает веб-панель во встроенном браузере. Через неё мод получает команды с сервера и отправляет результаты обратно.

### Как это работает

1. Игрок получает код в Telegram и вводит его в меню **Esc → Telelock**. Сервер связывает эту установку игры с аккаунтом Telegram.
2. Игрок выбирает режим поиска в Telegram. Бот отправляет команду серверу, а мод забирает её при следующей проверке. Команда привязана к конкретной установке и имеет срок действия.
3. Мод открывает штатный выбор героев и подтверждает состав, если игра разрешает. Бот получает подтверждение начала поиска, когда Deadlock действительно встаёт в очередь.
4. Когда игра сообщает, что матч найден, мод передаёт событие серверу. Бот отправляет уведомление согласно настройкам. В режиме **Авто** уведомления приходят о матчах, поиск которых запущен через бота.

Для работы нужны запущенная игра, интернет и действующая привязка. Ранговый режим и «Уличная стычка» доступны для запуска, когда сама игра предлагает эти режимы.

### Как собирается архив

Скрипт сборки берёт нужные экраны из установленной игры, добавляет панель и скрипты Telelock и компилирует ресурсы в VPK. Затем он проверяет целостность архива и наличие всех семи файлов. Исходники можно посмотреть в [папке мода](mod), а порядок сборки — в [скрипте сборки](mod/build.ps1).
