# Доставка команд и состояние связи, 13 ноября 2026

На снимке игрока сообщение о тайм-ауте осталось после успешной фоновой
проверки связи. Новый нативный интерфейс очищает именно ошибку соединения
после успешного ответа. Ошибки операций не стираются обычным обновлением.

Прежний транспорт последовательно запрашивал status и poll и ждал 1,5 с
через setTimeout скрытой страницы. Задержка фоновых CEF-таймеров является
возможной причиной минутного ожидания, но в игре она пока не измерена.

Новый мод каждые 1 с через Panorama Schedule меняет hash транспортной
панели. Страница обрабатывает hashchange и делает один запрос poll, который
возвращает поколение привязки и команду. Браузерный таймер опроса убран;
одновременно выполняется не более одного poll. ACK хранится нативно вместе
с поколением. После смены поколения ожидание подтверждения героев отменяется.

Сервер передаёт тип режима. Мод локально открывает штатный выбор героев и
пытается подтвердить его при доступной кнопке; второй сетевой запрос для
подтверждения не нужен. Валидация состава героев остаётся штатной.

Команды содержат expires, который проверяется транспортом и повторно
нативным скриптом до запуска. Это предотвращает запуск по ответу,
задержавшемуся после серверного срока 30 с.
