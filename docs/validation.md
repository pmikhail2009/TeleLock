# Проверка работы и сбор доказательств

## Панель Telelock в Deadlock, 13 ноября 2026

Через S2V сравнены ресурсы QOL и Telelock. У обеих разметок PanoramaLayout v3,
у скриптов PanoramaScript v4. Разметка Telelock содержит поле кода и кнопки.
Тип транспортной панели в сборке заменён с HTML на CitadelHTMLPanel по
работающему примеру QOL.

На установленной сборке Deadlock 26546669 после перестановки архивов
панель Telelock появилась по центру меню Esc. Telelock находится в addons/pak01_dir.vpk,
QOL перенесён в addons/pak17_dir.vpk. Содержимое QOL совпадает с сохранённой
копией mod/build/qol-original-pak01.vpk. В состоянии менеджера модов эта
перестановка не зарегистрирована.

Сборка Telelock для этой проверки находится в
mod/build/b7e2019a-8c53-40a9-9ca2-24ed4cb7840f/package/pak17_dir.vpk.
Публичный HTTPS-сервис опубликован по адресу
https://katka-game-gateway.pmikhail2009.workers.dev. Развёрнута версия
75c23a56-3b63-4200-96cf-b6eaab214dae с Durable Object Pairing. Настроены секреты
бота katkaV2_bot и служебной связи. Telegram Serverless и GitHub Pages
обновлены этим адресом. На публичном сервисе проверены статус новой
установки, отказ при неверном коде и отказ в служебной команде с чужим ключом.

В реальном личном чате TheKATKA команда /start выдала код подключения.
В открытой игре осталась старая загруженная версия транспортных файлов.
Сборка mod/build/51737825-e4ff-4066-9774-aa4589443056/package/pak01_dir.vpk
включает исправленные настройки прозрачности, ожидание привязки и обновление
транспортной страницы при новой сессии игры. Её установка остановлена
ошибкой автоматической проверки разрешений из-за лимита использования.
Установленный pak01_dir.vpk пока соответствует сборке b7e2019a.

Привязка и уведомления через панель пока не проверены. Поиск матча
при проверке не запускался.

## Выполнено при реорганизации

13 ноября 2026 года проверены:

- Синтаксис всех 10 Python-файлов.
- Импорт модулей с подменой внешних зависимостей и наличие всех шести картинок по новым путям.
- Маршрутизация команды своего чата, игнорирование чужого чата, обновление offset и запуск наблюдения после успешного поиска — с подменой Telegram и автокликов.
- Общий сигнал остановки наблюдения при отмене.
- Отказ от обращения к API при пустой конфигурации.
- Состав файлов по правилам Git: 23 файла; локальные данные и .env исключены, обнаруженный токен в этих файлах отсутствует.

Проверки выполнены рабочим Python 3.12 из среды инструментов. Реальные зависимости приложения, Telegram, рабочий стол и Deadlock в этих проверках не использовались. Сквозная работоспособность остаётся непроверенной.

## Подготовка

1. Пересоздать окружение Python 3.12 и установить requirements.txt.
2. Перевыпустить найденный в исходниках токен; заполнить локальный .env.
3. Проверить личный chat_id; открыть Deadlock вручную.
4. Проверить область экрана и соответствие шести картинок интерфейсу.

## Журнал испытаний

Испытания ещё не проведены. Заполнить фактическими результатами, без токенов и личных данных участников.

| Дата | Обезличенный участник | Разрешение/масштаб | Команда | Ожидаемый результат | Фактический результат | Задержка, с | Ошибка/исправление |
| --- | --- | --- | --- | --- | --- | --- | --- |
| — | — | — | — | — | — | — | — |

Считать отдельно реальные матчи, обнаруженные матчи, пропуски, уведомления без матча и задержку. Полнота = обнаруженные реальные матчи / все реальные матчи; точность = верные уведомления / все уведомления. При нулевом знаменателе показатель не рассчитывается.

Для сравнения «до и после» использовать одинаковые сценарии: сколько времени нужно следить за экраном вручную и с Telelock, каковы задержка и число пропущенных матчей. Не считать всё ожидание автоматически сэкономленным временем.
