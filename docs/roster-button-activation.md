# Активация кнопки подтверждения

Игрок сообщил: сборка 63710a48 открывает выбор героев, но не начинает очередь.
Прежний скрипт отправлял CitadelRosterSelectConfirm из контекста dashboard.
Это не воспроизводило штатный onactivate кнопки в контексте popup.

Теперь скрипт находит видимое окно по отдельному классу KatkaRosterSelect,
не заменяя его ID (игра может назначать ID динамически), и отправляет
Activated именно его ConfirmButton с источником mouse. Штатный обработчик
кнопки вызывает CitadelRosterSelectConfirm и сохраняет валидацию ростера.
Повторная доставка команды, отмена и срок ожидания обрабатываются как раньше.

Сборка 54d95283-515f-460d-8af9-2e5075c9f1fc установлена после сообщения
пользователя о закрытии игры. SHA256 установленной VPK совпадает со сборкой.
Предыдущая версия: mod/build/before-roster-button-activation-pak01.vpk.

Компиляция и проверка VPK S2V прошли; все восемь локальных проверок
command.test.mjs, settings.test.mjs и transport.test.mjs прошли.
Проверка активации убеждается, что целью является конкретная штатная
кнопка, но не доказывает выполнение очереди в движке. Реальный поиск
не запускался. Успех новой реализации в игре пока не подтверждён.
