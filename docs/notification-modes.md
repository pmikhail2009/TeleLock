# Режимы оповещений

В меню Esc → Telelock кнопка «Оповещения» переключает ВКЛ → ВЫКЛ → Авто.
Выбор сохраняется в локальном хранилище игрового браузера и применяется
без повторного подключения Telegram. По умолчанию выбран Авто.

- ВКЛ: уведомлять о любом найденном матче.
- ВЫКЛ: не отправлять автоматические оповещения о найденном матче.
- Авто: уведомлять только при запуске поиска через бота.

Ручной запуск режима, отмена поиска, смена привязки и найденный матч
сбрасывают признак запуска через бота. Получение команды без исполнения
не включает Авто. Проверочное уведомление и ответы на команды доступны
во всех режимах. «Включить наблюдение» не меняет выбранный режим.

Обновление требует новой VPK и размещённой HTML-панели.
Пояснение про Авто добавлено в справку Telegram Serverless и локального сервера.
