# Задержка проверочного уведомления

Кнопка проверки в меню Telelock отправляет сообщение
«Уведомление! Измеряем задержку…», затем обновляет это же сообщение:
«Уведомление! Задержка составила 1234 мс (1,234 сек)».

Замер начинается при нажатии кнопки в игре и заканчивается, когда игровой
браузер получает подтверждение успешного sendMessage от Telegram через
шлюз. В него входят передача запроса из игры, предварительная проверка
привязки и обратный ответ. Основной интервал измеряется монотонными часами
игрового браузера; время до обработки нажатия передаётся из Panorama.
Редактирование сообщения не входит в указанный интервал.

Bot API не сообщает момент доставки push на устройство или отображения
сообщения пользователю. Указанное время — до подтверждения Telegram,
а не измерение доставки на телефон.

Редактировать можно только последнее тестовое сообщение своей установки
и текущей привязки в течение пяти минут. Идентификатор Telegram-сообщения
не принимается от клиента. Сервер сам сохраняет его и адресата; клиент
возвращает случайную квитанцию и измеренный интервал. Изменение привязки,
чужая квитанция, отрицательные и слишком большие интервалы отклоняются.
Ошибки Telegram не показываются в игре как успешная проверка.
