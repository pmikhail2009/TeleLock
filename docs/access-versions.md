# Telelock — от геймеров для геймеров

С 25 ноября 2026 года в исходном коде Telelock нет платной подписки Pro или
пробного периода. Все игровые функции доступны обычному аккаунту `free`:

- запуск обычного, рангового режима и «Уличной стычки», когда они доступны в игре;
- статус подключения и поиска матча;
- отмена поиска и отдельное включение наблюдения;
- уведомления ВКЛ, ВЫКЛ и Авто с синхронизацией настроек с игрой;
- проверочное уведомление и повторное напоминание через 15, 30 или 60 секунд.

Сохранённые настройки уведомлений действуют для любого игрока. Старые записи
`proTrial:*` больше не влияют на доступ. Привязка аккаунта и проверка поколения
подключения по-прежнему обязательны для управления своей игрой.

Роли `owner` и `test` сохраняют служебные права: просмотр отзывов, административную
статистику и экспериментальные инструменты. Открытие игровых функций не выдаёт
пользователям служебную роль. Пароли и правила их включения остаются прежними.

## Благодарность

В главном меню вместо Pro находится «Сказать автору спасибо» / “Thank the author”.
Нажатие сохраняет благодарность аккаунта и показывает
«Ваше спасибо зарегистрировано👍» / “Your thanks have been registered👍”.
Кнопка «Отправить монетку автору❤️» / “Send the author a coin❤️” открывает
https://t.me/zzzMister. Поддержка добровольная и не влияет на игровые возможности.

Команда `/pro`, прежние подписи кнопок и callback `pro:pay` ведут к благодарности,
чтобы старые сообщения в Telegram продолжали работать. Подписку они не создают.

## Порядок выпуска

1. Выполнить проверки и создать Git-коммит только с изменениями этой задачи.
2. Опубликовать Gateway, затем обработчики Telegram и `lib/controls.js`.
3. Опубликовать HTML-панель по адресу, используемому VPK.
4. Собрать VPK, проверить ресурсы и контрольные суммы, установить при закрытой игре.
5. Опубликовать актуальную сборку на GameBanana.
6. Отправить объявление командой `node tools/broadcast-free-model.mjs --send`.

Без `--send` команда только показывает русский и английский тексты.
Перед отправкой проверяются рабочие обработчики, Gateway, webhook и панель.
Получатели берутся из привязок и выданных кодов; язык и клавиатура выбираются
по настройкам каждого аккаунта. Журнал в исключённой из Git папке `build`
предотвращает повторную отправку при перезапуске. Неподтверждённые доставки
нельзя автоматически повторять: сообщение могло уже дойти.

Публикация, установка и рассылка требуют отдельной проверки результата.
Готовый исходный код или VPK сами по себе не подтверждают рабочий выпуск.
