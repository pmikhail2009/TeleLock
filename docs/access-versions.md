# Бесплатная и скрытые версии Telelock

Бесплатный режим разрешает запуск трёх режимов и уведомления в Telegram.
Оповещения всегда «Авто»: только для поиска через бота. Переключение
оповещений, отмена через Telegram, отдельное наблюдение и проверочное
уведомление недоступны. Подключение, справка и отключение Telegram остаются
доступны, чтобы пользователь мог управлять привязкой.

Скрытые роли `owner` и `test` дают полный доступ. Отправка пароля обычным
сообщением в личный чат включает соответствующую роль. Повторная отправка
того же пароля выключает её только у отправителя. Тестовый пароль работает
у нескольких людей независимо. Пароль владельца закрепляется за первым
аккаунтом и не может быть использован другим аккаунтом. Выход не снимает
закрепление. Роли сохраняются на сервере независимо от переподключения игры.

Пароли не перечисляются в меню. При смене роли клавиатура обновляется;
игровое меню получает новую роль при следующем запросе статуса.
Сохранённые ранее «ВКЛ»/«ВЫКЛ» игнорируются в бесплатном режиме.
Право отмены проверяется сервером также для ручной команды `/cancel`.
Очередь повторно фильтруется при выдаче команд после выхода из полного доступа.

## Подготовка и публикация

`node tools/configure-access.mjs` создаёт личный и общий тестовый пароли
в исключённой из Git папке `build/access`. Повторный запуск их сохраняет.
Исходные пароли находятся в `Пароли.txt` и `passwords.json`;
на сервер отправляются только SHA-256 из `worker-secrets.json`.

Для включения в рабочем сервисе нужно:

1. Опубликовать Gateway вместе с `access.mjs`.
2. Загрузить оба значения из `worker-secrets.json` как секреты Worker
   (`wrangler secret bulk build/access/worker-secrets.json --config gateway/wrangler.jsonc`).
3. Обновить `handlers/message.js` и `lib/controls.js` в Telegram Serverless.
4. Пересоздать `serverless/dist/index.html` из `mod/panel/index.html`, сохранив
   адрес Gateway, и опубликовать панель по прежнему URL.
5. Собрать и установить новую VPK для отображения ограничений в меню игры.

Изменения относятся к текущей связке Gateway + Telegram Serverless + Panorama.
Старый Python-бот и резервный SQLite-сервер отдельного запуска здесь не менялись.
Автоматические проверки не заменяют испытания реального матча и доставки Telegram.
