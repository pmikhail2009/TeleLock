# Тестовая сборка Telelock — в резерве

С 22 ноября 2026 года тестовая сборка выведена из текущей разработки. `mod/Telelock.cmd` работает только с обычной версией; выбор тестовой отключён. Установленный в игре обычный VPK не заменялся.

Сохранены без удаления:

- прежний тестовый VPK: `mod/build/telelock-versions/reserve/lab/pak17_dir.vpk`;
- тестовый VPK с локальным профилем: `mod/build/telelock-local-profile-20261122/reserve/lab/pak17_dir.vpk`;
- его страница: `mod/build/telelock-local-profile-20261122/reserve/panel/lab/index.html`;
- исходный ZIP с обеими версиями, прежний переключатель, документация и контрольные суммы: `mod/build/reserve/telelock-lab-20261122/`.

Для возврата прежнего переключения нужно вернуть каталог `telelock-versions/reserve/lab` на место `telelock-versions/lab` и восстановить `mod/switch-telelock.ps1` из `switch-telelock.before.ps1` в резерве. Тестовый исходный код, `mod/panorama/lab.xml` и ручной параметр сборки `-Lab` сохранены. Ниже оставлено описание диагностики на случай возврата; оно не означает, что тестовая версия сейчас активна.

Тестовая панель использует отдельный каталог `/lab/` на том же домене и одну привязку Telegram с обычной версией.

В меню Esc тестовая версия помечена как **Telelock — тестовая версия**. Кнопка с названием режима переключает варианты, а **Замерить сейчас** запускает запрос, если предыдущий уже завершён.

| Режим | Что проверяет |
| --- | --- |
| Текущий маршрут | Полный ответ статуса с обычными настройками предварительного запроса |
| Кэш предварительного запроса | Тот же ответ и разрешение повторно использовать предварительный запрос 600 секунд |
| Короткий статус + кэш | Ответ только с данными для игрового меню и тот же кэш |

Полный цикл измеряется от отправки команды Panorama до получения заголовка от встроенного браузера. HTTP, шлюз и обработка ответа показываются отдельно при наличии метрик браузера. В консоль Deadlock пишется одна строка `Telelock lab status` на попытку. Для сравнения соберите серию каждого варианта с открытым окном и серию после сворачивания. Первый запрос отмечайте отдельно, так как он прогревает соединение и кэш.

Отправьте **`/lab_play`** в личном чате бота из аккаунта с ролью владельца. Команда запускает **реальный обычный поиск**. Когда игра подтвердит вход в очередь, бот покажет время от принятия заявки шлюзом до получения отчёта игры. Отдельное число показывает время до первого ответа шлюза с командой. На получение команды отводится до 30 секунд. При работе со списком героев действуют штатные условия игры. Остановить поиск можно через **`/cancel`**.

## Публикация

Для работы этих функций опубликуйте Gateway из `gateway/wrangler.jsonc`, `handlers/message.js` в Telegram Serverless и тестовую панель в каталоге `lab/` на GitHub Pages. Для публикации панели укажите действующий адрес шлюза в `meta[name="katka-gateway"]`. Тестовый VPK собирается через `mod/build.ps1 -Lab` с `-PanelUrl`, указывающим на этот каталог.
