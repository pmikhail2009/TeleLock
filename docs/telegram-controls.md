# Кнопки Telegram Telelock

Обновлено 13 ноября 2026 года. Изменения опубликованы в Telegram Serverless
и Cloudflare Worker версии `4cf4fcf2-17dd-4997-a0a5-0b777ee529b3`.
Для этого обновления замена VPK и перезапуск Deadlock не нужны.

После успешного подключения сообщение подтверждения показывает постоянную
клавиатуру: выбор режима, включение наблюдения, отмена поиска, проверка
привязки, справка и новый код. Уже подключённый игрок может открыть её
командой `/menu` или `/start`. Новый код сохраняет меню действующей привязки.

Выбор режима открывает отдельную клавиатуру. Кнопки с ▶️ отправляют
существующие команды `/play_normal`, `/play_ranked` и `/play_street`.
Текст меню предупреждает о запуске поиска и необходимости доступного
режима в самой игре. Возврат в управление ничего не отправляет игре.

Статус означает действующую привязку Telegram, а не доступность запущенной
игры. Проверка берёт поколение привязки из Telegram Serverless и сверяет
с текущим владельцем в общем реестре. Удалённая или заменённая привязка
не разрешает отправку команд. Сервер повторно проверяет владельца и
поколение при постановке команды в очередь. Игровой запрос не может
выбрать другого владельца через поле owner.

Проверка: `node --experimental-vm-modules --test serverless/test/controls.test.mjs`.
Все 9 проверок прошли: меню без запуска, преобразование кнопок в команды,
изоляция владельца, устаревшая привязка, групповой чат, потеря связи,
выдача кода и клавиатура в подтверждении подключения. Команды поиска
проверялись только с подменой сервера, без живого клиента.

В рабочем Telegram Serverless выполнен безопасный `/menu` для тестового
владельца из локальной конфигурации. В Telegram Desktop подтверждены
получение сообщения управления и появление BotKeyboard. Живые команды
поиска не отправлялись. Полный снимок Telegram не получен: автоматическая
проверка отклонила захват посторонних личных чатов.

Это проверка кнопок бота. Сквозная проверка выполнения команд игрой,
реального матча и доставки уведомления о матче остаётся отдельной работой.
